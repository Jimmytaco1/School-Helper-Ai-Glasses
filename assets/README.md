# Your own pictures

Put images in this folder and the app uses them automatically (restart the app after adding them):

| File name | Where it appears |
|---|---|
| `logo.png` (or `.jpg`) | the browser tab icon, and the top of the left sidebar |
| `banner.png` (or `.jpg`) | a wide picture across the top of the page |

Tips: a square logo (about 256 x 256 pixels) works best; a banner about 1600 pixels wide and 200 to 300 tall looks good. Only use pictures you own or have the right to use.
